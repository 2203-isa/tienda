# Academia Técnica HH · V14

Aplicación educativa estática (HTML/JS) para aprender reparación de computadores, Windows, drivers y ofimática con simuladores. Todo es ficticio: no modifica el equipo.

- 12 aulas, 11 laboratorios, 24 lecciones (2 preguntas cada una), 9 retos de ofimática, 4 evaluaciones con certificado, 3 exámenes por nivel con banco ampliado, revisión de errores y exportación (CSV, .doc, HTML).
- Instalable desde Chrome (manifest + service worker). El avance se guarda solo en el navegador.

Despliegue: subir esta carpeta a Vercel.
