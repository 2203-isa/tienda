# HH Limpia ✨

App Android para liberar espacio en el celular:

- **Fotos**: separa las tomadas con la cámara, capturas de pantalla, descargadas/recibidas (WhatsApp, Telegram…), **comprobantes de pago**, **capturas e imágenes de IA**, **capturas de internet**, archivadas y la papelera.
- **Videos**: de la cámara, descargados, archivados, grabaciones de pantalla, pesados (+100 MB) y repetidos.
- **Repetidos**: copias idénticas y fotos/videos parecidos, con la original marcada con ⭐ (se queda).
- **Nubes**: conecta las carpetas de OneDrive/Samsung, Google Drive, Dropbox, MEGA y Box y te dice qué ya tiene copia y qué no.
- **Apps**: lista las apps que menos usas, cuánto pesan y para qué sirven, y las desinstala en fila.

Todo se borra **de una vez**: marcas lo que quieras y Android pide una sola confirmación.

## Instalar

1. En el celular abre la página **Releases** de este repositorio y descarga `HH-Limpia.apk`.
2. Ábrelo. Si Android lo pide, permite "Instalar apps desconocidas" para tu navegador.
3. Abre HH Limpia y da los permisos.

Cada vez que se sube un cambio a `main`, GitHub compila un APK nuevo automáticamente.

## Notas

- Todo el análisis (incluida la lectura del texto de las capturas) se hace **dentro del celular**; no se sube nada.
- Internet solo se usa si tocas "¿Para qué sirve?" en una app (busca su descripción en Google Play).
- Google Fotos e iCloud no permiten que otras apps vean tu biblioteca, así que no se pueden revisar desde aquí.
